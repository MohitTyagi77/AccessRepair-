# Contributing to AccessRepair

First off, thank you for considering contributing to AccessRepair! Small efforts lead to a more accessible web for everyone.

## Code of Conduct

Help us keep the project open and inclusive by being respectful and helpful.

## How Can I Contribute?

### Reporting Bugs
- Use the GitHub Issue Tracker.
- Describe the bug precisely (steps to reproduce, expected vs. actual behavior).
- Include screenshots if applicable.

### Suggesting Enhancements
- Check if the feature has already been suggested.
- Open an issue describing why the feature would be valuable.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints.

## Style Guide

- Follow ESLint rules.
- Maintain consistent naming (camelCase for variables, PascalCase for React components).
- Comment complex logic, especially in AI prompt engineering parts.

## Project Structure

- `frontend/`: React Vite app.
- `backend/`: Express server, AI providers, and Playwright scanner.
- `shared/`: Shared types or utilities (if any).
- `docs/`: Additional documentation.

Thank you!
